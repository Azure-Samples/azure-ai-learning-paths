## Readiness check

Demonstrate a small change completed with AI assistance and explain:

- How the task was specified and bounded.
- Which context and tools the agent received.
- How generated changes were reviewed and tested.
- Which decisions still required human judgment.
- How secrets and sensitive data were protected.
