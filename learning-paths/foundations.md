## Core topics

| Topic | Start here | Outcome |

## Readiness check

You should be able to explain:

- Why a specific model fits a scenario.
- When to use grounding and how to evaluate retrieval quality.
- How identity, networking, content safety, and cost affect the design.
- Which quality and safety metrics you would test before release.
- How you would deploy and operate the application repeatably.
