# Security Policy

## Reporting security issues

Do not report security vulnerabilities through public GitHub issues.

Report vulnerabilities in Microsoft products and services through the [Microsoft Security Response Center](https://msrc.microsoft.com/report/vulnerability/new).

For vulnerabilities in a linked open-source project, follow that project's security policy.

## Repository content

This repository contains learning links and guidance. Never contribute secrets, credentials, customer information, private repository content, or sensitive organizational data.
