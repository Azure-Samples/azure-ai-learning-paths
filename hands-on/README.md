# Hands-on Resources

Use these public repositories to supplement the learning paths with practical experience.

## Selection guidance

Choose a sample that matches your learning goal and available environment. Before deployment:

1. Read the repository license and security guidance.
2. Review the architecture and expected Azure resources.
3. Estimate potential consumption costs.
4. Use non-sensitive sample data.
5. Remove resources when the exercise is complete.

## Suggested evidence of learning

For the selected sample, document:

- What problem it solves.
- Its main components and data flow.
- Identity and security boundaries.
- Evaluation and monitoring approach.
- Expected cost drivers.
- What you would change for production use.
