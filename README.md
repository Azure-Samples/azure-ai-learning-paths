# Azure AI Learning Paths

A curated, role-friendly collection of public learning resources for building, evaluating, securing, deploying, and operating AI solutions with Microsoft Azure and the Microsoft Copilot ecosystem.

## Choose your route

| Goal | Recommended route |
| --- | --- |
| Build a shared AI foundation | [Foundations](learning-paths/foundations.md) |
| Build pro-code applications and agents on Azure | [Foundry agents](learning-paths/foundry-agents.md) |
| Build agents with Copilot Studio | [Copilot Studio](learning-paths/copilot-studio.md) |
| Delegate work across Microsoft 365 | [Copilot Cowork](learning-paths/copilot-cowork.md) |
| Use AI throughout software delivery | [Agentic development](learning-paths/agentic-development.md) |

## Suggested sequence

1. Complete the core topics in [Foundations](learning-paths/foundations.md).
2. Select one solution track based on the scenario you want to build.
3. Complete at least one hands-on sample from the selected track.
4. Add [Agentic development](learning-paths/agentic-development.md) practices to your engineering workflow.
5. Review [credentials](credentials.md) and [cost-planning resources](cost-planning.md) when relevant.

This repository is a guide, not a requirement to complete every resource. Product availability, names, prerequisites, and licensing can change. Verify current details on the linked publisher pages.

## Learning outcomes

After completing a suitable route, learners should be able to:

- Explain common generative AI and agent concepts.
- Select an appropriate Microsoft platform and agent architecture for a scenario.
- Ground an AI solution in approved data and connect it to tools safely.
- Evaluate quality, safety, security, reliability, and cost.
- Deploy and operate a solution using repeatable engineering practices.

## Resource map

| Area | Concepts | Training | Practice |
| --- | --- | --- | --- |
| Foundations | Models, grounding, prompts, evaluation, security, operations | Microsoft Learn paths | Public samples and reference architectures |
| Foundry agents | Tools, MCP, orchestration, observability, red teaming | Agent development paths | Framework repositories and Azure samples |
| Copilot Studio | Harness selection, knowledge, tools, workflows, governance | Harness-specific paths | Agent Academy and public samples |
| Copilot Cowork | Delegation, reusable skills, plugins, administration | Cowork path and AB-6008 | Public labs and scenario runbooks |
| Agentic development | Specifications, instructions, MCP, review, SRE | GitHub Copilot paths | Public repositories and field guides |

## Using the resources responsibly

- Use non-sensitive sample data in labs.
- Review each repository's license before reusing code.
- Use approved subscriptions, tenants, and development environments.
- Treat estimator output as planning guidance, not a binding quote.
- Confirm current product availability and regional support before making architecture decisions.
