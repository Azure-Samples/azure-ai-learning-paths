# Contributing

Thank you for helping improve Azure AI Learning Paths.

## Good contributions

- Fix a broken or redirected link.
- Add a current public resource with clear learning value.
- Clarify prerequisites or outcomes.
- Remove obsolete or duplicated material.
- Improve accessibility and navigation.

## Resource criteria

A proposed resource should:

- Be publicly accessible.
- Have a clear owner or publisher.
- Provide meaningful documentation, training, or practice.
- Avoid customer data, private repositories, internal recordings, or confidential material.
- Include licensing information when it contains reusable code.

## Pull requests

1. Create a focused branch.
2. Make the smallest coherent change.
3. Explain the intended audience and learning value.
4. Confirm that every added link is publicly accessible.
5. Do not include credentials, secrets, personal information, or internal-only content.

By contributing, you agree that your contributions will be licensed under this repository's MIT License.
